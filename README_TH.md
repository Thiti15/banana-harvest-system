# ระบบติดตามการเก็บเกี่ยวกล้วย — รุ่นเพิ่มฟังก์ชัน

เวอร์ชันนี้ต่อยอดจากระบบเดิม โดย **คงฟังก์ชันเดิมทั้งหมด** และเพิ่มฟังก์ชันสำหรับพรีเซนต์/ใช้งานจริงมากขึ้น

## ฟังก์ชันเดิมที่ยังอยู่ครบ

- เข้าสู่ระบบ แยก **ผู้ดูแลระบบ (Admin)** และ **ผู้ใช้งาน (User)**
- หน้า Dashboard ภาพรวม
- เพิ่ม / แก้ไข / ลบแปลง (ลบได้เฉพาะ Admin)
- กำหนดผู้รับผิดชอบแปลง
- บันทึกการออกเครือเป็นหลายรุ่นในแปลงเดียว
- คำนวณวันคาดเก็บเกี่ยวอัตโนมัติ
- แสดงจำนวนวันที่เหลือและสถานะ
- บันทึกว่าเก็บเกี่ยวแล้ว
- ประวัติการเก็บเกี่ยว
- จัดการผู้ใช้งาน (Admin)
- เชื่อม Google Sheets ผ่าน Google Apps Script
- **QR Code ประจำแปลง** พร้อมดาวน์โหลด และสแกนดูข้อมูลแปลงจากมือถือได้

## ฟังก์ชันที่เพิ่ม

### 1) การแจ้งเตือนบน Dashboard
แสดงรุ่นที่เหลือไม่เกิน 14 วัน และรุ่นที่เลยกำหนดเก็บเกี่ยว

### 2) ปฏิทินวันเก็บเกี่ยว
เมนู `ปฏิทินเก็บเกี่ยว` แสดงวันคาดเก็บของแต่ละรุ่นในรูปแบบปฏิทินรายเดือน

- เดือนก่อน / เดือนถัดไป
- กลับเดือนปัจจุบัน
- แยกสีตามสถานะ
- กดรายการในปฏิทินเพื่อเปิดรายละเอียดแปลง

### 3) รายงานการเก็บเกี่ยว
เมนู `รายงานการเก็บเกี่ยว`

- กรองช่วงวันที่
- กรองแปลง
- กรองสถานะ
- สรุปจำนวนรุ่น / จำนวนต้น / เก็บแล้ว / รอเก็บ
- พิมพ์รายงาน
- บันทึกเป็น PDF ผ่าน Print > Save as PDF
- ดาวน์โหลด CSV

### 4) สถานะ Google Sheets
Admin มีเมนู `ฐานข้อมูล Google Sheets`

- แสดงสถานะการเชื่อมต่อ
- แสดงเวลาที่รีเฟรชข้อมูลล่าสุด
- ปุ่มรีเฟรชข้อมูลจาก Google Sheets
- ปุ่มเปิด Google Sheets

```text
├─ README_TH.md
└─ backend/
   └─ Code.gs
```

## การใช้งานกับระบบเดิม

ไฟล์ `config.js` ตั้งค่าไว้กับระบบปัจจุบันแล้ว ได้แก่

- Google Apps Script Web App URL
- GitHub Pages URL
- Google Sheets URL

ดังนั้น หาก URL เดิมยังใช้งานอยู่ สามารถอัปโหลดไฟล์หน้าเว็บชุดนี้ขึ้น GitHub เพื่อแทนไฟล์เดิมได้เลย

## วิธีอัปเดต GitHub Pages

ให้แทนไฟล์เดิมใน Repository ด้วยไฟล์เหล่านี้:

```text
index.html
app.js
api.js
config.js
data.js
styles.css
README_TH.md
```

`backend/Code.gs` **ไม่จำเป็นต้องอัปโหลดขึ้น GitHub Pages** ถ้า Apps Script ตัวเดิมยังทำงานอยู่

หลัง Commit ให้รอ GitHub Pages อัปเดตประมาณ 1–2 นาที แล้วเปิด:

```text
https://thiti15.github.io/banana-harvest-system/
```

จากนั้นกดรีเฟรชหน้าเว็บ

## ถ้าต้องการเปลี่ยน Code.gs

1. เปิด Google Sheets > ส่วนขยาย > Apps Script
2. นำโค้ดใน `backend/Code.gs` ไปแทนโค้ดเดิม
3. บันทึก
4. ถ้าเป็นการตั้งค่าครั้งแรก ให้รัน `setupSheets()`
5. Deploy > Manage deployments > Edit > New version > Deploy
6. สิทธิ์ Web app ต้องเป็น **Anyone / ทุกคน**

## บัญชีทดสอบ

```text
Admin
ชื่อผู้ใช้: admin
รหัสผ่าน: 1234

User
ชื่อผู้ใช้: user
รหัสผ่าน: 1234
```

หากบัญชี User เคยถูกแก้รหัสผ่านในหน้า `จัดการผู้ใช้งาน` ให้ใช้รหัสผ่านล่าสุดแทน

## QR Code

QR ของแปลงจะสร้าง URL ในรูปแบบ:

```text
https://thiti15.github.io/banana-harvest-system/?plot=PL001
```

ผู้สแกนไม่จำเป็นต้องเข้าสู่ระบบเพื่อดูข้อมูลแปลงและรุ่นการเก็บเกี่ยวของ QR นั้น

## หมายเหตุ

ระบบต้องใช้อินเทอร์เน็ต เพราะเว็บไซต์อยู่บน GitHub Pages และฐานข้อมูลอยู่บน Google Sheets / Google Apps Script
